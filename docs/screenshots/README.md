# FujiX native UI screenshot provenance

`native-editor-controls.png` and `native-fuji-panel.png` were cropped from real screenshots of the **FujiX ChromaForge native application on November 5, 2026**. Only the control/sidebar portions are shown: no personal photographs, private albums, user file paths, or imported creator recipes are visible.

They illustrate real UI design work from the earlier installed version; they are **not generated graphics**, nor proof the currently published changes have been compiled and installed. Physical Fujifilm X100VI camera slot C1–C7 writes and readback remain **unverified**. Source-only verification and rebuild limitations are discussed in [FUJIX-PUBLICATION.md](../../FUJIX-PUBLICATION.md).

The original open-source ChromaForge repository is **[emmertex/chromaforge](https://github.com/emmertex/chromaforge)**. Its upstream demo screenshots and source license notices remain credited in this repository; the underlying project was forked from [storytold/lightcraft](https://github.com/storytold/lightcraft).
